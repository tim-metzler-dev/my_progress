  1. Hex-Code.
      The first two digits represent red
      The next two represent green
      The last two represent blue
       for example. ffffff means full red, green, blue. You can add other values to make it more invisible... I mean clearer. But I'll hear more from that later.

  3. font-weight   controls the boldness of a text. It's quite nice! There are also a few values:
        I. normal → Regular weight (default)
       II. bold → Bold text
      III. lighter → Lighter than the parent element
       IV. bolder → Bolder than the parent element
Numeric values:
        A. 100 (thin)
        B. 400 (normal)
        C. 700 (bold)
        D. 900 (extra bold)
